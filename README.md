# Book Management Application

## Description
The Book Management Application is a web based system designed to manage and organize book records efficiently. 
It allows users to add, view, update, and delete book details using CRUD operations. 
The application provides a simple and user-friendly interface for managing book information.

##Live Demo
https://sabithra-m.github.io/A-Book-Management-Application/

## Features
- Add new books
- View book records
- Delete book entries
- Easy data management
- User-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript
